# news21-v4

A single-page news illustration — "THE WORLD IN ONE DAY", Saturday 21 November 2026 — produced for the make.fun news-image bounty. The entry is the `entry.png` front page: a hand-typeset newspaper with a date banner, six headline cards and a 24-story ticker spanning seven regions, complete with a where-it-happened map and date-check notes.

## Run it

```bash
node main.ts
```

The script copies `entry.png` into `MAKEFUN_OUTPUT_DIR` (default `/output`) and reports the copied byte size on stderr.
